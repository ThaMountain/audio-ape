# AA-014 synthetic audio fixtures

These files are original deterministic sine tones generated by
`scripts/generate_aa014_fixtures.py` with Python's standard-library `wave` module. They contain no
third-party recording or composition and are public-domain-equivalent test data.

- `aa014_01b_tone_a.wav`: mono 16-bit PCM, 44,100 Hz, 440 Hz tone, exactly 132,300 frames / 3.000 s.
- `aa014_01a_tone_b.wav`: mono 16-bit PCM, 44,100 Hz, 660 Hz tone, exactly 176,400 frames / 4.000 s.

There is no encoded leading or trailing silence. The intentionally reverse-lexicographic `01b`
then `01a` names prove that playback order comes from trusted numeric ordering fields, never raw
filename sorting.
